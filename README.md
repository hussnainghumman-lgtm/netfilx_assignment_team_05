# 🎬 Netflix Data Analysis Project

## 1. Project Overview

This project focuses on analysing Netflix-style data to understand movie characteristics, genres, ratings and user viewing behaviour.

Our selected business challenge is:

**Challenge 1: What Makes Content Popular on Netflix?**

We use Python and data analysis techniques to explore the dataset and identify useful business insights.

## 3. Project Objectives

- Analyse Netflix movie data.
- Explore popular movie genres.
- Analyse movie ratings and release years.
- Understand user viewing behaviour.
- Identify the most active users.
- Create visualizations to present findings.
- Provide business insights and recommendations.

## 4. Dataset Description

Our project contains three datasets:

| Dataset | Number of Records |
|---|---:|
| Users | 10 |
| Movies | 10 |
| Watch History | 10 |

The datasets contain fictional practice data created for educational purposes.

## 7. Data Analysis Process

Our project follows these steps:

1. Import Python libraries.
2. Load and inspect datasets.
3. Check missing values and duplicates.
4. Clean and prepare the data.
5. Perform Exploratory Data Analysis (EDA).
6. Analyse movie genres and viewing patterns.
7. Create data visualizations.
8. Identify business insights.
9. Present conclusions and recommendations.

## 8. Visualizations

The project includes:

- Watch Records by Movie Genre.
- Users by Subscription Plan.
- Completed vs Not Completed Watches.
